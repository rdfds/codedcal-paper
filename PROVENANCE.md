# Scientific provenance

This is an independent research snapshot from revision
`76026acdbe41c92c0f3db1d0e4cbae1faeedb415` of
`https://github.com/rdfds/codedcal-research`.
The source research repository is preserved intact.

`provenance/import.json` records every imported file's original path, Git blob,
SHA-256, current path/hash and any documented transformation. Scientific arrays
are copied byte-for-byte. Some derived JSON records normalize workstation paths;
all numeric, Boolean and null leaves were checked unchanged during export.
A cache default was made relative and an obsolete branch-maintenance sentence
was omitted. These changes are explicitly recorded and do not reclassify outcomes.
The new file manifest seals the resulting portable snapshot; it does not pretend
that a normalized file still has its original byte hash.

The new repository begins with fresh Git history. Only selected immutable file
blobs are reused as independent copy-on-write files. No original commits, linked
worktrees, alternate object stores, hard links or symlinks are required. Source
commit identifiers establish lineage; they do not establish external registration
or prove that outcomes had not been inspected.

The curation focuses on the current paper and its complete retained numerical
checks. Wider historical archive searches, old paper drafts, venue planning,
execution supervisors and submission administration remain in the original
archive. Complete relevant data, comparator matrices, failures and exclusions
are retained here. The manuscript and its declarations are separate documents.

The portable reconciliation checker retains the original numerical recount body.
Its historical workstation-dependency prologue is replaced by this repository's
full file-manifest check. Numerical assertions, confidence rules and tolerances
are unchanged. Exact covariance recount code and the packaged numerical modules
are transferred unchanged.

A subsequent reporting review adds a weighted-input model note and exact finite-law
controls. Figure2's axis and descriptive metadata now identify filtered paired-
bootstrap ranges explicitly. Every underlying value, validity rule and numerical
module remains unchanged. The import ledger retains the original source hashes
and records the revised description/display hashes separately.

The subsequent reporting correction makes the four-panel averaging explicit,
clarifies realized-weight conditioning and distinguishes known-mean-centered
Monte Carlo second moments from sample covariance. Its read-only exports add
historical/float64 baselines, observed-tile support and a descriptive accounting
of conservative coverage. The original qualifications, numerical modules,
retained arrays and old study documents are unchanged. Current expositions
are separate in `methods/temporal-model.md`, `methods/covariance-reporting.md`
and `methods/prior-work.md`. The licence scope points to this snapshot's
DATA.md rather than an excluded historical directory.


The public paper repository is an independently rooted snapshot of this
research companion, with no earlier Git parents, branches or development
messages. File identities, source software revisions, excluded cases and
failure records remain. Four nonessential source/site captures are excluded
under `provenance/external-source-omissions.json`; this is a disclosure of the
public snapshot's scope, not deletion from the preserved research archive.

The final package audit restored two omitted regression fixtures from their
preserved source blobs: the unmodified VA142 codebook and the analytic geometric
kernel witness. Their identities and distinct rights are recorded in
`provenance/test-fixtures.json`. This repairs test completeness without changing
any numerical module, threshold or retained scientific outcome.
