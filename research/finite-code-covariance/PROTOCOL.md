# Finite-code covariance extension — 27 October 2026

This bounded extension is developed on research/finite-code-covariance in the
curated repository. Historical sources, estimates, confidence sets and manuscript
claims remain unchanged. The original development repository is untouched.

## Questions and scope fixed before comparative outcomes

1. Derive conditional *joint* covariance of the implemented four-panel Fourier
   numerator/reference statistics, including windows, frequencies, angles,
   orientations and real/imaginary parts. Distinguish code randomization from
   physical-field variation using total covariance.
2. Determine exactly what restricted symmetrization/uniqueness establishes;
   exclude universal efficiency or information lower-bound claims.
3. Check a code-allocation improvement under explicit costs, retaining cases
   where it vanishes or reverses. Code changes are hypothetical physical source
   alphabets, never post-acquisition relabeling of localization events.

Independent uniform permanent source codes; source contributions fixed and
independent of codes. General K >= 3. Real observation vectors may combine any
trilinear phase/count terms linearly. The covariance theorem is exact conditional
on contributions, not an exact distribution/coverage theorem for ratios.
Arithmetic and geometric ratio gradients are first-order approximations only;
unsupported denominators or geometric ratios must remain unsupported. A
code-dependent displacement breaks the conditioning assumption.

## Verification fixed before outcomes

- Exact rational enumeration of code kernels and count-only moments.
- Independent exhaustive assignments for unequal finite complex source phases,
  comparing source-index decomposition, direct kernel, and shipped H3 output.
- Exact small-N direct-coefficient versus contraction covariance, PSD,
  cross-frequency/cross-window covariance, Re/Im, and scaling/permutation tests.
- Counterexamples: fixed-factor cancellation; N=3 nonlinear ratio removes the
  toy ratio-of-sums penalty; violations of code exogeneity; nonuniform codes;
  shared acquisition displacement does not create independent realizations.
- Derivative checks for arithmetic and geometric log attenuation; no replacing
  shipped Fieller sets with delta intervals.

historical SHA-256 records. Streaming summaries may use every retained field;
paired assignments share a physical field and are not independent replicates.
No historical generator's mutating run/main entry point may be called.

For exact source-level verification, replay only the **first 16 groups of
physical replicate 0** in every world, from the original saved seed and template
IDs using the preserved generator. Match known-source and both coded arrays
against their retained values before using reconstructed source contributions.
All nine views/eight acquisitions and both noise laws are included. This is a
fixed exposed development prefix, not independent validation or all-group
prediction. Retain empty groups. Code-offset worlds are replay controls outside
the conditional exogeneity theorem, not fitted exceptions.

For every exogenous prefix, compute covariance averaged over its sixteen groups.
Verify conditional predictions with 512 new code assignments to these *fixed*
observations, deterministic seeds. These assignments are numerical verification,
not new physical or biological replicates. Retain Monte Carlo errors and tails;
do not tune settings to improve agreement or a method's apparent performance.
If exact replay fails, retain the discrepancy and stop that comparison pending
an explicit implementation repair; do not relax gates after examining outcomes.

## Design comparison

Predeclared K grid: 3,4,6,8,12,16,24,32,48,64. Evaluate exact conditional code
covariance and full covariance = physical floor + coding covariance. The physical
floor is estimated descriptively from retained known-source group contributions,
with whole-physical-field uncertainty where feasible. Prefix code covariances do
not certify full-acquisition design optima. Report arithmetic/geometric targets
separately, with their own population gradients; no changed-target recovery win.

Costs: (a) same independent groups, increasing alphabet cost; (b) B=K*G, total
code-plus-physical variance multiplied by K; (c) B=(1+0.25*(K-4))*G for K>=4,
an explicitly illustrative lower marginal code cost. Compare against K=4 and
known-source information-rich floor. Include q=0 cancellation and high physical
floor controls where extra codes cannot improve a fair-budget measurement.
Do not recommend a hardware optimum without a supported physical cost model.

No free group splitting, photon reuse, newly opened acquisitions, paid jobs,
cloud jobs, reserved pixels or new physical outcome study. Persist small results,
source hashes, errors, failures and reproducible commands. Literature comparison
must distinguish classical Hoeffding decomposition, moment sketches, cumulants,
SOFI/kICS and ratio inference from application-specific conclusions.

## Completion and stopping

Report whether there is (i) an exact mathematical result; (ii) quantitative
agreement under stated conditions; (iii) a useful equal-budget conditional design
improvement; (iv) evidence supporting implementation/manuscript promotion.
A standard decomposition or hypothetical cost benefit is not a newly established
physical capability. No manuscript upgrade is automatic. Commit proof, tested
implementation, verification, comparison and interpretation separately.

## Dated finite-budget verification amendment

After the first exact-covariance/replay pass (whose design scores are exposed),
add a numerical check of *finite ratios*, without selecting a winning K. This
is retrospective computational validation, not a new external outcome study.
Use all 108 exogenous worlds, including both kernel violations, and the same
fixed sixteen source-observation groups. The empirical distribution placing
mass 1/16 on each complete group is the declared conditional observation law.
Its mean and physical-floor covariance are known exactly from those sixteen
source diagonals. Use this consistent law for BOTH variance terms and ratio
targets; do not silently combine a prefix code variance with a different
population's physical floor. Preserve the original mixed-sample descriptive
scores as preliminary population estimates, never a certified design optimum.

For each world compare K=4,8,16, budget B=256, hence G=64,32,16 independent draws
from that empirical distribution, with fresh independent source codes. Exactly
200 simulated experiments per K, deterministic seeds. The three methods target
the same prefix population for each variant. Retain both frequencies, both
variants, every sign/support failure, full Fieller-set type, usable coverage,
width, point-error tails and first-order influence variance. Use the shipped
arithmetic Fieller and geometric Bonferroni rules via independently checked
sufficient-statistic calculations. Do not select K using these outcomes.

This is a finite-state conditional design verification, not photon-budget or
hardware validation, not new independent preparations, and not proof that the
prefix accurately estimates a whole preparation. The budget law still assumes
unchanged photons, source counts, kernels and target as K changes. An improved
variance alone must not be described as improved usable measurement coverage.
