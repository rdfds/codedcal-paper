## What this extension can add

An exact conditional covariance for the **implemented** source-coded finite
Fourier statistics, including shared-code window/frequency dependence, coupled
to a physically separate observation-variation floor; a narrow optimality
statement with the five-orbit condition explicit; and finite-budget verification
of when added code information improves or worsens measurement usability under
an explicitly stipulated cost law. The computational derivation and resource
logic are useful applications of established mathematics, not a new theory of
cumulants, moment sketches, Fieller inference or universal optimality.

This audit found no inspected source containing this exact four-panel calibration
covariance/design package. That is a bounded search result, not proof of priority.
The generic theorem alone is unlikely to bear a large standalone novelty claim.
Publication importance requires the application-specific result to be informative,
correctly scoped and useful alongside the existing reconciliation evidence.
