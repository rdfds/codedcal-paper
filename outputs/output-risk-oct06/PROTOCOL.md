# Output-risk development qualification — 6 October 2026

This study tests a consequential uncertainty diagnostic, not whether our search
wins. All BARseq3 fields, culture Position351 and tissue tile_1 are already
exposed development. No reserved kidney fields, D076 pixels or other STARfinder
fields will be opened. A passing exposed result is not independent confirmation.

Target: predict >5 percentage-point loss of native identity consistency or
composition TV >0.05, from observed conditioned images, support, physical book
and fitted transforms. The native consistency endpoint uses common source-frame
coordinates and fixed interior support, not independent molecular truth. Readout
weights/noise conditioning remain source-dependent; no Poisson camera likelihood,
RNA FDR, posterior credibility or formal uncertainty-coverage claim follows.

Core: a deterministic finite transform profile. Include ordinary method starts,
strong selected maps, the unchanged group-search's per-partition best fits and
prespecified local alternatives around the strongest author solution. Canonical
first-frame gauge; fixed spatial blocks. On common support, compute the pinned
single-code projected residual from unchanged inverse-sampled input voxels.
Resample block sufficient statistics, never concatenate synthetic image blocks.
500 resamples, seed 61021, compatibility: paired 2.5th-percentile loss excess over
best <=0.002. This is an empirical screening rule, not a calibrated probability.
Min12 usable blocks, common coverage >=0.8, incumbent >=10 calls; otherwise abstain.

Propagate compatible transforms through the unchanged decoder interfaces. Flag
if any compatible alternative changes incumbent identity by >=0.05 or composition
by >0.05. Select the incumbent by observed loss among ordinary author/template
final maps, not outcome F1 or known injection. Include strong full-volume author
color fitting in tissue. Compare unfiltered disagreement among the same
conventional starts, unfiltered full-bank disagreement (including search), fit
loss, best-candidate loss gap, blank-derived proxy and decoder margin. Do not omit the full-bank baseline
if it predicts as well. Identity/confidence/kernel thresholds remain unchanged.

Common coordinate domain: BAR z0, xy40:88; culture/tissue z8:22, xy40:88.
Profile/calibration region uses z0 or z8:20 and xy40:88, blocks (1 or4,12,12).
Decoder inputs use each retained integer map in its original gauge; decoded
coordinates then subtract that map's first-frame shift. Catalog comparisons
retain radius3, with native references translated into the
observed first-frame gauge only in the evaluator. Truth offsets and reference
calls never enter the core or compatibility choice. Changes from historical
80-pixel windows are explicit: do not recycle their aggregate F1 labels.

Candidate bank: retained final ordinary maps and all available retained author /
template starts, per-family/per-partition group-search best maps, the selected
group map, plus single-color +/-1 pixel x/y shifts and individual non-first-round
+/-4 pixel x/y shifts about the strongest ordinary author map. Deduplicate by

Do not use oracle/refined-from-oracle transforms. No support-driven per-method

13 development cases: BARseq3 fields0,1 ×zero/common/color; culture ×those3;
tissue ×zero/common/color/outclass. BAR has two actual kernels; STARfinder has
source lookup and the actual correlation/nonnegative kernels. These conditioned

Resource gate: first run all 13 cases with correlation and the STARfinder source

report nonnegative propagation as unrun. This gate is fixed before new outcomes,
not a decoder chosen because it wins. No cross-family validation is claimed
from the first stage.
