# Full-volume conventional barcode-model comparator

The exposed repaired tissue color case has a 7–9 point identity advantage for the
unchanged bounded group search over the strongest tested 2D barcode optimizer.
A 3D image-template comparator was included, but a full-volume barcode optimizer
was not. Test that concrete alternative before claiming a durable benefit.

Use the pinned, unmodified BarDensr find_translations_using_model on the complete
16 × 30 × 128 × 128 calibration window, physical 64-word book, 50 iterations per
start, padding/wiggle (3,10,10). Starts are zero, the retained 3D image template,
and the retained 2D author solution embedded in 3D. Never seed with group search,
oracle, native labels or imposed offsets. Retain initial and rounded refined
candidates; choose lowest actual full-volume coded loss, then map norm and name.
Transfer that map to scoring window 4, retaining the three existing source spot,
correlation and nonnegative-regression catalogs, thresholds, support accounting,
identity radii and composition endpoint. Report all failures and fit/decoder time.

This focused additional comparator tests the already exposed color case only.
It is development, not a new preparation confirmation or natural RNA truth.
Numerical qualification checks full-volume loss and exact inverse XYZ alignment,
finite actual-author 3D optimization and same-object oracle recovery before
comparator outcomes. Spec and passing controls must be committed before running.
