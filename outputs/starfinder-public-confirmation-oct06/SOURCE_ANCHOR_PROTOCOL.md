# Source-color-constrained input-object score — exposed diagnosis

The unconstrained direct input-object score prevents the pixel-rule's native
harm, but still misses the tissue color benefit. Its group advantage is .00235,
with paired object bootstrap interval including zero. Do not simply lower the
threshold. A source peak was detected in a particular first-round color; the
unconstrained score can instead explain it with another source/color.

Test a declared conditional source-assignment model: the molecule responsible
for a color-c anchor has a code whose first readout is c. Restrict each anchor's
projection to those physical words. Keep every other score parameter, input
sampling coordinate, support penalty, .005 margin, complexity order and endpoint
unchanged. No native gene identity, imposed error or winning method is supplied.
This uses an available first-round measurement, not a new instrument intervention.
It assumes the detected source color is attributable; overlap/crosstalk can violate
that assumption, so this is not a complete mixture/censor-aware reference model
or an RNA correctness guarantee. Retain duplicate anchors and uncertainty.

This is post-hoc development on exposed tissue. Numerical controls before score
outcomes cover round gains, exact corrections, missing support, zero flow and
mislabelled first-source color. Every failed rule stays. A passing result still
requires frozen independent field/acquisition testing and cannot retroactively
turn the failed original tissue study into a confirmation.
