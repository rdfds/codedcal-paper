# Reproduction environments

Use `temporal-exact.txt` with Python 3.10 for the exact interval recount. Use `figures-current.txt` with Python 3.13 for Figures 1, 2 and 4, and `figures-tested.txt` with Python 3.10 for the historical Figure 3. Pass that second interpreter through `--selection-python`. The earlier `package-tested.txt` records the historical package environment; current export test versions are in `checks/verification.json`. There is no single environment asserted to reproduce every historical study.
