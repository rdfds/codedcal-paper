# Supplementary Note 1A. Weighted inputs and descriptive bootstrap ranges

## Optional event weights require a weighted observation model

The default unit-weight model uses the number of events as the panel count.
For optional positive event weights, the implemented inputs instead are

\[
Z_{st}(q)=\sum_\ell w_{st\ell}\exp(iqX_{st\ell}),\qquad
n_{st}=\sum_\ell w_{st\ell}.
\]

Let $N_{st}$ denote the raw event count, distinct from the weighted sum $n_{st}$.
Define $F$ as the sigma-field generated by source positions/nuisance, the full
raw count profile and every realized weight $w_{st1},\ldots,w_{stN_{st}}$,
excluding the assigned codes. Thus $n_{st}$ is $F$-measurable. For $n_{st}>0$
require the conditional weighted characteristic function

\[
\frac{1}{n_{st}}\sum_\ell w_{st\ell}
E[e^{\mathrm{i}q\epsilon_{st\ell}}\mid F,D]=\psi_s(q;F)
\]

to be independent of panel and displacement realization. Equivalently,

\[
E[Z_{st}(q)\mid F,D]=n_{st}e^{\mathrm{i}q(\theta_s+D_{s,w(t)})}\psi_s(q;F).
\]

A common conditional event-error characteristic function independent of the
weights is sufficient; it is not necessary if the weighted averages agree.
Conditional panel factorization, code exogeneity relative to this full profile,
and the original common displacement-characteristic condition given $F$ are
also required. Zero-count panels contribute zero triple-product weight.
Consequently both moments contain $n_{sa}n_{sb}n_{sc}|\psi_s(q;F)|^2$ and the
conditional population identity follows. Conditioning only on a weight law
while treating realized $n_{st}$ as fixed would be a different model.

Positive weights alone do not establish these conditions. Photon-, precision-
or quality-dependent weighting can change the conditional error law or
selection differently across panels; interface acceptance does not validate
their observation model.

The shipped-API controls in `tool/tests/test_weighted_target_contract.py`
enumerate one stationary source, all $3^4$ independent uniform {-1,0,1} error
states at frequency $\pi/3$ and all four permanent source codes. There is
one event per source/panel in each state. The actual four-panel opposite-window
count averaging and pooling are defined in Supplementary Note 1, Section 3.
The error-dependent weights are explicitly $w(0)=1$ and $w(-1)=w(1)=2$ in B;
window A uses unit weights.

For fixed panel weights (1,3,2,5), the expected cross and reference moments
are identical: both equal 14/3 in window A and 80/9 in window B. When window A
uses unit weights and window B instead gives weight two to nonzero errors,
the unweighted error law remains unchanged but the weighted kernels differ.
The expected (cross, reference) moments become (2/3,20/27) and (10/9,1).
The arithmetic population ratio is then 48/47 despite zero physical motion.
The geometric ratio equals one in this example, retaining that successful
alternative without a general guarantee. These exact quadrature controls
are not independent preparations or physical validation.

## Paired bootstrap ranges describe retained valid draws

The historical reference reconciliation uses 2,000 paired resamples of the
occupied coarse-group tiles of the observed 4-by-3 spatial partition
(7–12 tiles by view). A tile with no selected sources remains in that
view's resampling frame. A draw contributes only if its reference
denominators and ratios satisfy the original positivity conditions. A range
is reported only when at least 95% of draws are valid, and uses the central
95% of those valid draws. Invalid-draw counts remain in the retained records.

These are central 95% valid-draw percentile ranges conditional on inferred
source assignments, the observed spatial blocks, selection and sign validity.
Filtering changes the summarized distribution. No calibrated physical 95%
coverage, simultaneous error control, equivalence or independent-replication
claim is established. Positive ranges describe residual disagreement on that
conditional law; ranges containing zero do not establish equivalence. Field names
such as `conditional_interval` remain unchanged for reproduction.

These descriptive ranges are distinct from the frequency-specific approximate
Fieller confidence sets. The latter retain their own group-mean approximation,
support rules and unusable outcomes; neither construction verifies physical
source identity or the observation assumptions.
